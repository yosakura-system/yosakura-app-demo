# 世桜アプリ（デモ版）

高原社長にお見せするための、**「世桜という1つの窓口アプリ」**のデモです。

## コンセプト
- **1つのアプリが大本の窓口**。その中に多数の業務アプリ（食べ残し報告・一食目写真・総括表・マニュアル・本部ダッシュボード…）が入る。
- **権限で出し分け**。役割（スタッフ／店長／オーナー／本部）ごとに、見える・入れる機能が変わる。
- **すべてここで管理**。現場の報告が本部ダッシュボードに自動で集約される流れを実演。
- **ホーム画面に追加すると世桜ブランドが立ち上がる**（PWA・アイコン／スプラッシュ付き）。

## 触りどころ（高原社長へのデモ手順）
1. 上部の **「デモ・役割」チップ**をタップ → 役割を切り替える。
2. **スタッフ**では本部メニューが施錠（グレー）で見える＝権限の概念が伝わる。
3. **食べ残し・食材ロス報告**（● LIVE）は実際に入力・保存できる。
4. 役割を**本部**に切替 → **本部ダッシュボード**を開くと、今の報告が集計されて表示される（現場→本部の流れ）。
5. ブラウザの「ホーム画面に追加」でインストール → 世桜アイコンで起動。

## ローカルで動かす
静的ファイルのみ。ローカルサーバーで開くと PWA（インストール・オフライン）まで確認できます。

```
cd 09_世桜アプリ_デモ
python -m http.server 5173
# ブラウザで http://localhost:5173 を開く（スマホ表示にすると実機の見え方に近い）
```

※ `index.html` を直接ダブルクリックでも画面は出ますが、インストール／Service Worker はローカルサーバー（localhost）でのみ有効です。

## そのまま無料公開（GitHub Pages）
同じPWA方式。このフォルダをリポジトリのルート（または docs/）に置いて Pages を有効化するだけ。独自アイコン・スプラッシュ・インストールがそのまま効きます。

## 本番化するときの構成（デモとの違い）
- 現在：データは**この端末内（localStorage）**にのみ保存。ログインは無く、役割は手動切替。
- 本番：**GAS（Google Apps Script）＋スプレッドシート**をバックエンドにして無料運用可能。ログイン／権限は Google アカウント or 簡易認証で付与。既存の提出物管理シート・サーベイとも同じ思想で接続。

## ファイル
- `index.html` … 入口 / `styles.css` … デザイン / `app.js` … 画面と権限ロジック
- `manifest.webmanifest`・`sw.js` … PWA（インストール・オフライン）
- `icons/` … 世桜ブランドアイコン（`generate_icons.py` で再生成可能）

## これはデモです
- 「◆ デモ表示」と書かれた画面は見た目のイメージ（実データは動きません）。
- 実際に動くのは **食べ残し・食材ロス報告 → 本部ダッシュボード** と **開店チェック** です。
- 役割・機能・デザインはたたき台。ここから高原社長のご意見で作り込みます。
